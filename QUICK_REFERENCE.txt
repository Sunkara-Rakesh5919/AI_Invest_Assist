```

GET /api/cache-status

```

### WebSocket
```
subscribe(symbol)    - Subscribe to updates
unsubscribe(symbol)  - Stop updates
ping()               - Keep-alive
disconnect()         - Close connection
```

## 🔄 Frontend Integration

```javascript
// 1. Import client library
// <script src="backend/client.js"></script>

// 2. Create client instance
const apiClient = new BackendClient('http://localhost:5000');

// 3. Connect WebSocket
await apiClient.connectWebSocket();

// 4. Subscribe to updates
apiClient.subscribe('TCS', (data) => {
    console.log('Real-time update:', data);
});

// 5. Fetch data
const stocks = await apiClient.getStocks(['TCS', 'INFY']);
```

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| Port 5000 in use | Change PORT in .env |
| API keys invalid | Verify in .env file |
| WebSocket fails | Check firewall/CORS |
| Database error | Delete stock_data.db |
| npm install fails | Clear cache: `npm cache clean --force` |

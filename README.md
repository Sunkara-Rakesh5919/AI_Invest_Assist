## 🎓 **AI Methodology Explained**

Each stock gets scored through:

1. **Technical Analysis** (80% weight)
   - RSI indicator (50-90 range)
   - MACD signal crosses
   - Bollinger Bands positioning

2. **Fundamental Analysis** (60% weight)
   - P/E ratio assessment
   - Price-to-Book analysis
   - Return on Equity (ROE)

3. **Sentiment Analysis** (50% weight)
   - News sentiment score
   - Social media signals
   - Analyst recommendations

4. **Volume Analysis** (70% weight)
   - Trading volume trends
   - Volume spike prediction
   - Liquidity assessment

**Final Score** = Weighted average of all 4 components
